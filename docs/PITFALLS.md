# 已知限制与实测记录

## 目前的限制

- 沙箱没有 Rust 工具链，本地未编译；第一轮真实编译由 GitHub Actions 完成。
- V1 核心的 `find_before` 是从头正扫，超大文件上不是 O(1)。
- 非 ASCII 大小写折叠暂时不做完整 Unicode case folding。
- GUI、真实大文件 I/O、跨平台安装包和截图基准尚未接入。

## 测不出来

- 没有真实 GPU / 真机环境时，机器只能验构建和软件渲染路径，不能证明用户体感。
- “极简风格是否好用”不能靠 PNG 非空证明，必须人工验收。

## 阈值实测值

第一轮尚未采集性能基线，因此不写性能阈值。先记录打开、索引、搜索、替换和保存的真实耗时，再留至少三倍余量设置只抓卡死的门槛。
