# 带期限的义务

「等下次顺手做」是这类项目里最常见的谎。这里的每一条都有期限，完成判据读代码而不是读我的报告，
并且由 `crates/meta/tests/obligations.rs` 守：完成了还挂着也判红，因为一份挂着已完成事项的清单没人会再读。

新增一条义务时必须写两件事：`unix` 时间戳（否则没有任何东西能自动判到期），
以及一条**读代码**的完成判据（否则只能靠我自己声明完成）。两者都有断言守。

## 目前没有未完成的义务

## 不登记成义务的事（有理由的记录）

- **macOS / Windows 上的无头截图。** 目前只在 Linux 上跑截图与基准。要不要接上去，
  取决于那两个 runner 能不能稳定地起一个无头窗口，而这个得先跑一次才知道；
  它也直接进计费（macOS 十倍）。先写成记录，不假装它有截止日。
  在那之前，那两个平台能自动验的上限就是字体探测（不开窗口），屏幕上的事要人拍图。
- **上游 egui 对字体集合的支持细节。** 选脸（face index）现在自己解 cmap 挑，
  因为上游不告诉我哪张脸覆盖中日韩字。上游往后如果提供了覆盖查询，这一层就能变薄；
  时机不由我定，所以不给它定期限。
